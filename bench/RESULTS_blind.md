# 처음 보는 대상 세기 — "모르는 척" 실험 (2026-11-01~)

규칙: 대상 클래스로 학습된 검출기를 쓰지 않음. 클립마다 앞부분 점 K개가 든 구간만 사람 라벨로 보고, 평가는 각 클립 **뒤 절반**(`bench/analysis/score_half.py`).
비교 기준(대상을 아는 검출기): 차량 A8(RF-DETR+한 방향 세기), 보행자 MOT-A7-bottom(RF-DETR person+발 기준).

## 4단계: 띠 점 검출기(`strip_net.py --mode budget`, 800회)

| 대상 | 점 K(클립당) | 라벨 구간 | F1 | 재현율 | 정밀도 |
|---|---|---|---|---|---|
| 차량 5클립 | 20 | 5~18초 | **87.3** | 86.0 | 88.6 |
| | 50 | 13~39초 | 82.8 | 72.8 | 96.1 |
| | 100 | 26~68초 | 88.4 | 86.2 | 90.7 |
| | 200(앞 절반 한도) | 50~75초 | 88.2 | 84.7 | 92.0 |
| | (참고) 앞 절반 전부, 1500회 | 75초 | 89.1 | 85.3 | 93.2 |
| | **기준: 대상을 아는 검출기(A8)** | 0 | **97.1** | 96.5 | 97.7 |
| 보행자 MOT17 7개 | 5 / 10 / 20 (처음부터) | 1~18초 | 18.2 / 0.0 / 10.5 | | |
| | 5 / 10 / 20 (차량 띠 모델에서 시작) | | 22.6 / 29.1 / 19.0 | | |
| | **기준: 대상을 아는 검출기** | 0 | **80.4** | 83.0 | 77.9 |

- 차량: 점 20개(클립당 5~18초 라벨)로 87, 그 뒤로는 88 근처에서 포화 — 띠만으로는 약 88이 천장. 차로를 따라 한 방향으로 흐르는 대상에는 적은 라벨로 쓸 만한 출발점.
- 보행자: 실패(≤29). 군중이 선 위에서 겹치고 머물고 여러 방향으로 지나가 띠의 흔적만으로 개체를 나누기 어려움. 차량 모델에서 시작하면 조금 낫지만 무의미한 수준.
- → 띠 검출기는 "아무것도 모르는 대상"의 범용 안전망이 아니라, **흐름이 정돈된 대상(차로·컨베이어·통로)에서 라벨 몇십 개로 시작하는 빠른 경로**로 자리매김.
