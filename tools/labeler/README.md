# 정답 라벨러 (테스트용)

시공간 띠 위에 점을 찍어 "기준선 통과 이벤트" 정답을 만드는 실험용 도구. 실제 서비스용 툴이 아니다.
설계에서 확인한 내용은 기술 조사 문서의 "라벨링 툴 요구사항 v0"에 정리한다.

## 클립 추가
```
python3 tools/prepare_clip.py --video <영상> --camera dongtan-jct \
    --clip-id dongtan-day-01 --title "경부선 동탄분기점 · 주간 120초 · 2026-10-27 13:10"
```
- 기준선은 `counter/lines/<camera>.json` 하나만 고친다 (카운터와 공용).
- 웹 영상(`clip.mp4`)은 용량 때문에 레포에 넣지 않는다. 라벨러 게시본(아티팩트)에만 올린다.

## 사용
- 띠를 훑으며 틀린 점 삭제, 빠진 차 추가, 어긋난 점은 끌어서 조정
- 보이는 구간을 다 봤으면 "이 구간 검토 완료" (Enter)
- 내보내기 CSV를 `eval/gt/<clip_id>_vN.csv`로 저장. 골드 구간 = 검토 완료 구간
